# ۲۰۴۸ | باشگاه معما

بازی تحت وب با JavaScript، HTML و CSS و بدون وابستگی زمان اجرا.

```sh
npm ci
npm run dev
```

با کلیدهای جهت‌نما یا کشیدن انگشت روی صفحه بازی کنید. «لغو حرکت» صفحه و امتیاز پیش از آخرین حرکت معتبر را برمی‌گرداند؛ رکورد مرورگر تغییر نمی‌کند. بعد از ساخت کاشی ۲۰۴۸ می‌توانید بازی را ادامه دهید.

- `npm test` آزمون‌های منطق بازی را اجرا می‌کند.
- `npm run build` نسخهٔ قابل انتشار را در `dist/` می‌سازد.
- `game.mjs` قواعد بازی و `src.js` رابط، ورودی و انیمیشن را پیاده‌سازی می‌کند.
