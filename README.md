# بیان قرآن — Bayan Quran

یک وب‌سایت مدرن و کامل برای مطالعه‌ی قرآن کریم با طراحی **شیشه‌ای (Glassmorphism)**:

- متن عربی معتبر قرآن کریم (همه‌ی ۱۱۴ سوره، ۶۲۳۶ آیه)
- ترجمه‌ی فارسی آیت‌الله مکارم شیرازی، آیه‌به‌آیه
- تلاوت صوتی آیه‌به‌آیه با امکان ادامه‌ی خودکار (چند قاری بزرگ)
- نشانه‌گذاری آیه‌ها، جست‌وجوی سریع سوره، آیه‌ی روزانه، پوسته‌ی تیره/روشن و تنظیمات قلم

## اجرا

```bash
npm install
npm run dev     # سرور توسعه روی پورت 5173
npm run build   # خروجی تولید در dist/
```

## ساختار

```
index.html              ساختار صفحه
style.css               سیستم طراحی شیشه‌ای
app.js                  منطق برنامه (روتر، تلاوت، نشان‌ها، تنظیمات)
public/data/quran-meta.js   اطلاعات ۱۱۴ سوره + آفست‌های صوتی
public/data/quran-full.js   متن عربی و ترجمه‌ی فارسی ۶۲۳۶ آیه
scripts/build-quran-data.py   بازتولید فایل‌های داده از منابع
assets/                 تصاویر پس‌زمینه
```

## منابع داده

- متن قرآن: [fawazahmed0/quran-api](https://github.com/fawazahmed0/quran-api) (نسخه‌ی ساده‌ی عربی، بر پایه‌ی Tanzil)
- ترجمه‌ی فارسی: همان مخزن، نسخه‌ی `fas-nasermakaremshi` (آیت‌الله مکارم شیرازی)
- اطلاعات سوره‌ها: [risan/quran-json](https://github.com/risan/quran-json)
- صوت: [cdn.islamic.network](https://cdn.islamic.network) (قرائت مشاری العفاسی و دیگر قاریان)

> ترجمه‌ها جنبه‌ی کمک‌آموزشی دارند؛ برای استنباط احکام به تفاسیر معتبر مراجعه کنید.
