# طوفان خلیج ۳D | Persian Gulf Strike 3D

A 3D tactical missile & naval simulation game built with **Three.js**, **React**, **TypeScript**, and **Tailwind CSS** with a full Persian (RTL) command HUD.

## Features
- **10 Iranian Missile & Naval Strike Systems**: Fattah-2 (Hypersonic Glide Vehicle), Khalij Fars (ASBM), Khorramshahr-4 / Kheibar (MIRV 3-warhead split), Sejjil-2 (two-stage separation), Noor / Qader / Qadir (sea-skimming cruise), Abu Mahdi (flanking stealth cruise), Shahed-136 (5-drone swarm), Zolfaghar Basir, Emad / Ghadr (MaRV), and Hoot (supercavitating underwater torpedo).
- **Carrier Strike Group Target**: Procedural 3D **USS Abraham Lincoln (CVN-72)** with 5 targetable subsystems (Command Island, Flight Deck, Phalanx CIWS, Hangar & Ordnance Bay, Main Hull), plus escort Aegis vessels (**CG-53**, **DDG-111**, **DDG-77**) with active VLS SM-2/SM-6 interceptors, Phalanx CIWS tracer defense, and patrolling F/A-18 CAP aircraft.
- **Coastal Military Base**: Mobile TEL launchers, underground heavy silo, Bavar-373 SAM battery with Meraj-4 radar, Ghadir-class submarine, and Zolfaghar fast attack craft.
- **Tactical HUD & Cinematography**: Custom GLSL animated ocean shader, live sweeping 2D radar, 3D trajectory preview arc, 5 camera modes (`Orbit`, `Missile Chase`, `Carrier Deck`, `Launch Site`, `Cinema`), Time-of-Day presets, NVG/FLIR optics, slow-motion time scale, combined Salvo mode, and procedural Web Audio sound effects.
