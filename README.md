# تکتیک‌لب | Tactic Lab

آزمایشگاه فارسی مقایسهٔ کد ضعیف و اصلاح‌شده در پنج سناریوی Unity. این پروژه یک سایت آموزشی است؛ نمونهٔ شبکه فقط پیام‌رسانی لابی را محلی شبیه‌سازی می‌کند.

- `npm ci` برای نصب وابستگی‌ها
- `npm run dev` برای پیش‌نمایش محلی
- `npm test` برای بررسی ساختار درس‌ها
- `npm run build` برای خروجی ایستا در `dist/`

محتوای درس‌ها در `lessons.js` است و فایل [Markdown](public/lessons-fa.md) با `node build-lessons.mjs` به‌روزرسانی می‌شود. راهنمای Unity در سایت و فایل Markdown آمده است.
