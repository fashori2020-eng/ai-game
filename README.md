# بازی ۲۰۴۸

بازی کلاسیک ۲۰۴۸ تحت وب با HTML، CSS و JavaScript خالص.

## اجرا

```bash
npm install
npm run dev
```

سپس آدرس نمایش‌داده‌شده (معمولاً `http://localhost:5173`) را باز کنید.

## امکانات

- صفحه ۴×۴ با حرکت کاشی‌ها با کلیدهای جهت‌نما / WASD و کشیدن انگشت (swipe) روی موبایل
- ادغام کاشی‌های هم‌عدد و دو برابر شدن مقدار آن‌ها
- امتیاز فعلی و بهترین امتیاز (ذخیره در مرورگر با localStorage)
- تشخیص رسیدن به کاشی ۲۰۴۸ و امکان ادامه بازی پس از برد
- تشخیص پایان بازی وقتی حرکتی باقی نمانده است
- دکمه بازی جدید و لغو آخرین حرکت (Undo)
- طراحی واکنش‌گرا با رنگ متفاوت برای هر مقدار و انیمیشن روان لغزش، ظهور و ادغام

## فایل‌ها

- `index.html` — ساختار صفحه
- `style.css` — استایل و انیمیشن‌ها
- `src.js` — منطق بازی و ورودی‌ها
