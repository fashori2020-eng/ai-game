# افق | میدان تمرین آرکید

یک بازی تک‌صفحه‌ای فارسی و راست‌چین با نمای سه‌بعدیِ سبک آرکید که با Canvas و HTML/CSS/JavaScript ساخته شده است.

## اجرا

فایل `index.html` را در مرورگر باز کنید یا از ریشهٔ مخزن یک سرور استاتیک اجرا کنید:

```bash
python3 -m http.server 8000
```

## بازی

- یکی از کلاس‌های نمایشی را انتخاب کنید و «شروع تمرین» را بزنید.
- با ماوس یا کلیدهای جهت‌دار / WASD نشانگر را هدایت کنید؛ `Space` هم شلیک می‌کند.
- امتیاز و نتایج در همان نشست بازی ثبت می‌شوند.

نام تجهیزات و ناو صرفاً برای فضای داستانی بازی هستند؛ عملکرد، برد و مشخصات واقعی بازنمایی یا شبیه‌سازی نمی‌شوند.
